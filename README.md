# Mokepon-practica-con-platzi

## Descripción

Este es el proyecto que realicé junto al curso de programación básica de Platzi. En este proyecto aprendí a pensar cómo resolver problemas usando variables, funciones, ciclos y a empezar a pensar como un programador. Entré en contacto con JavaScript, HTML, CSS, Node.js y aprendí a usar cosas como el Canvas, cómo modificar el DOM, cómo hacer una API con mis propios endpoints y cómo consumirlos. Este es el proyecto que me inició en esto y espero hacer cosas más grandes.

## Dependencias

- **express** (^5.2.1) - Framework web para Node.js
- **cors** (^2.8.6) - Middleware para CORS

## Cómo ejecutar el proyecto

1. Instala las dependencias:
```bash
npm install
```

2. Inicia el servidor:
```bash
npm start
node index.js
```

El servidor estará disponible en `http://localhost:3000`
